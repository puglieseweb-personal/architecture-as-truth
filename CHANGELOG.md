# Versions of the wording

The wording of Architecture as Truth is versioned. A change to the definition, a principle or a rule is a new version with a date. Repository releases carry the same number, with a patch digit for changes that leave the wording as it is (templates, checks, the site).

## 1.0 · 2026-11-05

The first public wording: the definition, the five principles, the four rules for an AI agent, the caution about the name and what it needs. Published in the article *AI Promoted Everybody. Architecture as Truth (AAT) Is the New Job.* at https://www.puglieseweb.com/blog/architecture-as-truth and licensed CC BY 4.0 the same day.

### Repository 1.0.0 · 2026-11-06

The first release of this repository: the fixed wording, the agent file, the starter, the two checks, the checklist for tool builders and the reference site at https://architectureastruth.org/.
