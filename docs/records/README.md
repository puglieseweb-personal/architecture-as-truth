# Records

One dated record per change to this repository, named `YYYY-MM-DD-<slug>.md`: what merged, what changed, and which documents the change relied on. The wording in `ARCHITECTURE-AS-TRUTH.md` and the agent file in `agent/AGENTS.md` are this repository's approved truth; a change to either is an amendment, labelled `amendment` and merged by the author. `checks/record_check.py` checks every record here, and CI refuses a pull request that adds none.
